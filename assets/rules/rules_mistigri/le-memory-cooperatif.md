# Le Memory Coopératif

![Le Memory Coopératif](images/le-memory-cooperatif.jpg)
> Source : [Le Memory Coopératif](https://jeuxdecartes1.e-monsite.com/pages/jeux-de-memoire/le-memory-cooperatif.html)

♦ **Matériel** : Un jeu de 52 cartes (sans Joker) duquel on retire quatre cartes inutilisées

♦ **Nombre de joueurs** : Entre 2 et 6 joueurs

♦ **Objectif** : Réunir les cartes de même valeur en faisant le moins d’erreurs possible

♦ **Règle du jeu** : Dans cette version coopérative du [***Memory***](https://jeuxdecartes1.e-monsite.com/pages/jeux-de-memoire/le-memory.html), trois 7, trois 8, trois 9, trois 10, trois Valets, trois Dames, trois Rois et trois As sont mélangés et ordonnément disposés sur la table, face cachée, sans se superposer. Les 24 cartes restantes, rassemblées en un paquet, constituent les pénalités, c’est-à-dire le nombre maximum d’erreurs autorisées au cours de la partie.

Un joueur retourne une première carte et la laisse face visible ; le joueur suivant en retourne une deuxième :

1) Si les deux cartes sont de valeurs différentes, elles sont remises face cachée. L’équipe tire une carte de pénalité.

2) Si les deux cartes sont de même valeur, le joueur suivant en retourne une troisième :

- Si les trois cartes sont de même valeur, c’est gagné : le joueur les retire du jeu.
- Si la troisième carte n’est pas de la même valeur que les deux autres, toutes sont remises face cachée. L’équipe tire une carte de pénalité.

Les joueurs, qui jouent à tour de rôle, gagnent la partie si toutes les cartes ont été retirées du jeu avant épuisement du paquet.

Remarque : En cas de victoire, les joueurs peuvent enlever une carte de pénalité pour chaque partie supplémentaire, et ainsi, tenter de gagner avec un minimum de cartes de pénalité.
