# Le Baudet

**Nombre de joueurs :** 4
**Nombre de cartes :** 52
**Difficulté :** Moyenne
**Type :** Combinaisons
**But :** Se débarrasser le premier de toutes ses cartes
**Autres noms :** Le Baudet, Le Petit Cheval

---

## Préparation

Le donneur distribue les cartes **une par une**.

---

## Déroulement

### Principe

1. Les joueurs qui possèdent des **as** les sortent et les mettent sur la table, **faces visibles**.
2. Sur ces as viendront ensuite se placer les autres cartes de **même couleur**, d'abord les **2**, puis les **3**, et ainsi de suite jusqu'au **roi**.

### Règles de jeu

- On joue dans **n'importe quel ordre**.
- Les joueurs se débarrassent de leurs cartes **dès qu'ils le peuvent**.

> Chaque couleur forme une pile ascendante : As → 2 → 3 → … → Roi.

---

## Fin du jeu

### Variante 1 : Le premier gagne

Le gagnant est celui qui se débarrasse le **premier** de toutes ses cartes.

### Variante 2 : Le dernier perd

On joue la partie **jusqu'au bout**. Le dernier joueur restant est le **perdant** — le **baudet** (l'âne).
