# Tapp Tarock

**Difficulté :** —
**Type :** Tarot, Tarot
**But :** An Austrian Tarock game for three players. Links to rules.

---

This three-handed Austrian Tarock game is not often played. Nowadays the four-player games Königrufen and Zwanzigerrufen are far more popular.

A description can be found on this archive copy of Bernhard Krüpl's [Tarock Page](https://web.archive.org/web/20070514081801/http://www.webit.at/bk/tarock.html) and on the [Wikipedia Tapp Tarock](https://en.wikipedia.org/wiki/Tapp_Tarock) page.
