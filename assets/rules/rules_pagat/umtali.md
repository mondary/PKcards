# Umtali

**Difficulté :** —
**Type :** Rami
**But :** Comment jouer au jeu de cartes Umtali — lien vers les règles de ce jeu de rami de la Rhodésie coloniale.

---

Ce jeu de rami inhabituel aurait été populaire sur les voyages en train dans la Rhodésie coloniale. Umtali est l'ancien nom d'une ville marchande sur la ligne de chemin de fer Salisbury-Beira.

Les règles se trouvent sur cette [page Umtali](https://web.archive.org/web/wjm.0catch.com:80/umtali.html).
