# Polignac & Knaves

**Difficulté :** —
**Type :** Divers, Divers
**But :** Card games in which the object is to avoid winning Jacks in tricks.

---

These are games in which there is a penalty for each knave taken in tricks.

There were rules on Dave Barker's web site. Here is an archive copy of his [Knaves](https://web.archive.org/web/20020806135934/w3.one.net/%7Edbarker/cards/knaves.html) page.

Also, there were rules in French on Jean-François Bustarret's page [Polignac (ou jeu des Valets)](https://web.archive.org/web/20250114072704/https://www.jeuxdecartes.net/jeux-cartes/polignac/) (archive copy).
You can download a freeware Polignac program from [Thanos Card Games](https://thanoscardgames.jimdofree.com/).
