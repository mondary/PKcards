# Nomination

**Difficulté :** —
**Type :** Divers, Divers
**But :** Page sur les différentes versions du Nomination Whist. Ce nom désigne au moins trois jeux de cartes britanniques différents, dont deux sont populaires dans la Royal Navy.
**Autres noms :** Clag

---

Le nom **Nomination Whist**, parfois abrégé en **Nominations**, **Noms** ou **Nommies**, est utilisé en Grande-Bretagne pour désigner au moins trois jeux de cartes différents. Ils sont tous basés sur le Whist en ce sens que ce sont des jeux de levées simples avec atouts joués avec le jeu anglo-américain de 52 cartes. « Nomination » fait référence au fait qu'après la distribution, les joueurs nomment le nombre de levées qu'ils ont l'intention de remporter. Trois jeux portant ce nom sont décrits sur trois pages différentes de ce site. Ce sont :

- Un jeu qui est essentiellement le même que Oh Hell ! Tous les joueurs doivent prédire combien de levées ils remporteront, et il y a un bonus pour une prédiction exactement correcte. En général, le nombre de cartes distribuées à chaque joueur change d'une unité à chaque donne. Ceci est décrit en détail sur la page Oh Hell !

- Un jeu aussi connu sous le nom de Clag, qui est similaire au précédent, mais avec des donnes supplémentaires jouées selon des règles spéciales. Ceci est décrit en détail sur la page Clag.

- Un jeu plutôt différent pour quatre joueurs dans lequel toutes les 52 cartes sont distribuées. Dans ce jeu, les enchères sont compétitives, et le plus fort enchérisseur choisit un partenaire en appelant une carte. L'enchérisseur et le partenaire essaient ensemble de remporter au moins le nombre de levées enchéries. Les partenariats ne deviennent clairs que lorsque la carte appelée est jouée. Ce jeu est décrit en détail sur la page Noms.

Le premier et le troisième de ces jeux seraient populaires dans la Royal Navy. Selon le site [Navy Song](https://web.archive.org/web/20180723070149/http://myweb.tiscali.co.uk/navysong/Data%20Game/Noms%20%26%20Whist.htm) de Barry Scott, le jeu n°1 — similaire à Oh Hell ! — est le Nomination Whist avec les règles des « grands navires », tandis que le jeu n°3 — Noms — est le Nomination Whist avec les règles des « petits navires ».
