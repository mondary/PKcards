# Ramsli

**Difficulté :** —
**Type :** Divers, Divers
**But :** Un jeu hongrois de prise de plis avec des mains de quatre cartes, apparenté au jeu français Rams. Lien vers les règles.

---

Un jeu hongrois apparenté au jeu français **Rams**. Le jeu croate Raub est aussi similaire.

Une version de Ramsli jouée par les Donauschwaben — les colons allemands sur les rives du Danube — dans la Hongrie du XVIIIe et XIXe siècle est décrite sur la page [Jeux de cartes des Donauschwaben](https://rick-heli.site/gene/cards.html) de Rick Heli.
