# La Sizette

**Nombre de joueurs:** 2 ou plus
**Nombre de cartes:** 1 jeu de 32 cartes, plus les 6, soit 36 cartes.
**Difficulté:** Moyenne
**Type:** Jeu de plis
**But:** Parvenir a réaliser, le premier, trois levées. La Sizette ou Sixette est un jeu ancien dont les règles
