# Les As à l'As

**Nombre de joueurs :** 1
**Nombre de cartes :** 52 (sans les Fous)
**Difficulté :** Facile
**Type :** Patience
**But :** Retourner toutes les cartes de la table en les replaçant aux bonnes positions
**Autres noms :** Les As à l'As

---

## Règle courte

On n'utilise que 32 cartes dans ce jeu. Avant de jouer, il faut donc enlever les 2, les 3, les 4, les 5, les 6 et les Fous.

## Version longue

### Disposition des cartes

Déposez les cartes en quatre rangées de huit. Les sept premières restent face cachée, la dernière étant ouverte. Chaque emplacement doit être comblé par une carte prédéterminée.

### Début du jeu

Vous avez donc quatre cartes ouvertes. Servez-vous-en pour remplacer la carte correspondante, que vous retournez.

Si vous trouvez un As, mettez-le de côté.

L'objectif consiste à retourner toutes les cartes de la table.

Placez alors vos cartes ouvertes. Les cartes que celles-ci remplacent deviennent à leur tour des cartes ouvertes. Continuez jusqu'à ce que vous ayez placé toutes les cartes sur la table. Attention, vous ne pouvez le faire que si vous ne trouvez pas les quatre As dès le départ, d'où le nom de ce jeu. Facile à faire ? Soyez chanceux !
